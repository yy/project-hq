# HQ for iPhone

Open `HQMobile.xcodeproj` in Xcode and run the HQMobile scheme. Choose a development team under Signing & Capabilities for a physical iPhone.

HQ opens with an editable sample project. Tap the project to review its saved AI overview or expand Full notes. Tap + on the project list to capture a task. Desktop HQ reads captures from `_tasks/todo.txt`.

To try two devices, copy `SampleHQ` into a new iCloud Drive folder. On iPhone, tap the folder button and select that copy. The prototype recognizes the sample marker and reads the `projects` track. On the Mac, run `hq --dir "/path/to/copied/folder" serve` and open the printed address. Capture on the phone, check Todos on the Mac, then edit project notes on the Mac. Pull to refresh on the phone. The app also refreshes when it returns to the foreground.

Each `project.md.overview.json` holds desktop HQ's cached overview for `project.md`. The app compares its revision to the current notes and labels an older overview. The sample overview was generated by desktop HQ. Generating and exporting updated summaries automatically is future work.
